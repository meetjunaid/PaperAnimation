# Bundled fonts

Open-licensed stand-ins for the macOS design fonts, used only when the system
lacks the original (Windows, Linux). Each was cut to a static regular, bold,
italic and bold-italic instance and subset to Latin characters. Fonts with a
Reserved Font Name were renamed as the SIL Open Font License requires.
